# Orchestration agent entry point

For an explicit request to install or update Orchestrate, follow [the shared installation guide](docs/guides/agent-installation.md). In Codex, install the CLI and the six checked-in skill dispatchers into the current host's personal `~/.agents/skills/` location (or its established custom location).

These instructions apply only to explicit Orchestrate installation or update requests. Do not apply them to ordinary repository work.
