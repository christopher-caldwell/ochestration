# Work

Read the controller-generated `action.json` and the Build role guide. Implement the complete
delivery phase in the target checkout, run relevant checks, commit intended changes, then write
`report.md` and the exact `result.json` receipt. Do not edit `state.json`, choose another phase,
or start another role.
