# Build reliability: incident lessons

Earlier Build iterations accumulated preflight probes, executable forensics, acceptance callbacks, heartbeat supervision, provider/session recovery, evidence projection, operator resolution overlays, cleanup, export, and successor workflows. These mechanisms tried to infer progress or recover uncertain provider actions from incomplete evidence. They increased controller surface area and made a failed or interrupted action harder to reason about than the implementation itself.

The replacement is a deterministic gate runner. Before launch it writes an immutable action packet and invocation record, then durably marks that action `running`. A completed role returns one schema-checked JSON response. Rust validates only mechanical facts—action identity, commit ancestry and `HEAD`, clean disposable checkout, artifact lineage, and Audit coverage structure—then routes the fixed state machine. A restart while `running`, malformed output, provider failure, or a Git invariant failure stops for operator-directed reset rather than guessing whether a provider action can be replayed.

Checkpoint reset replaces recovery orchestration: the controller records the last accepted commit; explicit reset validates it, removes the current disposable worktree, restores tracked files to that commit, removes ordinary untracked files with `git clean -fd`, preserves ignored files, clears sessions, and requeues the same gate. One explicit blocked result may take one Unblock detour. This small, inspectable boundary is safer than replay ladders, replacement sessions, automatic continuations, or interpreting role prose as a repair policy.

Historical schema-v3 Build state is intentionally unsupported. Earlier accepted implementation commits are already in current product history, but an old in-flight state does not encode this checkpoint/reset contract. There is no reliable mechanical mapping from its recovery statuses, actions, or session state to the new state machine. Starting a new Build from current accepted artifacts is clearer than silently migrating ambiguous control state.
