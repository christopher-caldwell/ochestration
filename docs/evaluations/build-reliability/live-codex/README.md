## R-022: authorized live fixture capability probe

The `orchestrate build preflight --live --authorize-live` call used the exact three role configs in [config.toml](r022/settings/config.toml); once-over was absent. The selected roles, token cost, and isolated fixture effects were disclosed before the call. For this first run (and the rerun below) a temporary launcher applied `workspace-write` to Worker and `read-only` to Reviewer/Unblocker; its exact script and mode log are retained in [settings](r022/settings/). The later Worker-commit run used the real executable with no launcher.

The first call found that Worker could create `preflight-worker.txt` but Codex refused `.git/index.lock`, so no Worker commit was made. Reviewer and Unblocker returned their unique tokens and `git rev-parse HEAD` values in their transports, and their fixture trees stayed unchanged. The controller initially required these read-only roles to write a sidecar report; its `no_probe_evidence` result exposed a controller defect because the roles could not write under their requested sandbox. The Reviewer transport also records a read-only local app-surface inventory and denied attempts to open terminal/TextEdit/Cursor apps; no app was opened or changed.

### Read-only transport-evidence rerun

The controller now captures completed provider messages from its own `transport.jsonl` and retains them as the probe report when a sidecar is unavailable. Read-only probe prompts ask for the token and command output in the final response and prohibit file writes. The isolated regression proves a transport-only response is accepted only when it contains both the fixture token and current Git head and the fixture stays clean.

A bounded rerun used the same Worker `gpt-5.6-luna` / `medium` with `workspace-write`, Reviewer and Unblocker `gpt-5.6-sol` / `low` with `read-only`, and no once-over. Reviewer and Unblocker now both returned `read_and_command_verified`; independent Git status checks found no changes in either fixture. Their extracted final responses and original transports are retained in [the rerun evidence](r022/read-only-transport-rerun/). Worker again created the expected file but could not commit because the launcher's injected `workspace-write` policy denied `.git/index.lock`, leaving it untracked in its disposable fixture and producing `cannot_commit`.

### Worker commit and same-session resume through the configured path

A later bounded run on 2026-09-25 removed the temporary launcher from the execution path: static preflight resolved the real `codex` executable and, with the Worker explicitly configured `permission = "full_access"`, reported the provider-native argument `--dangerously-bypass-approvals-and-sandbox` (Reviewer and Unblocker, which omit `permission`, reported none). The authorized live preflight then returned `worker_commit_verified`: the Worker staged and committed `preflight-worker.txt` (commit `4fc39df2`), independently verified with Git. The same session (`01a0da36-77c1-70e2-9c4a-02f342ab7163`) was resumed through the production `CommandAdapter` — the same call the Build driver makes when a Work action continues — under the unchanged configured attributes, and the resumed turn committed `resume-worker.txt` (commit `36e3bf06`, parent the fresh commit). R-022's live Worker-commit criterion is met.

That run also exposed a real defect: the preflight's own fixture Git commands inherited stdout, so `build preflight --live --authorize-live` printed Git chatter before its JSON result and its stdout was not a single JSON value (the same leak is visible in the earlier `cli-stdout.log`). The fix captures those commands' output in `live_fixture`; the regression test `live_preflight_keeps_stdout_a_single_json_value` (a stub `codex` on PATH, no inference) fails on the pre-fix tree and passes on the fixed one.

Requested-versus-attested facts, raw transports, exit records, fixture bundles, the resume harness source and limits: [worker-commit/](r022/worker-commit/README.md).

The first controller result, fixtures, raw transports and limits are retained under [initial preflight evidence](r022/preflight-live-1790362155518/); the second result, fixtures, raw transports, extracted reports, stderr, exit code and fixture checks are under [transport-evidence rerun](r022/read-only-transport-rerun/).
