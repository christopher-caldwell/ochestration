# Orchestration agent entry point

For an explicit request to install or update Orchestration skills, follow [the shared installation guide](docs/guides/agent-installation.md). In Claude Code, install the six checked-in user-facing folders into the current host's personal `~/.claude/skills/` location (or its established custom location).

These instructions apply only to explicit Orchestration installation or update requests. They do not require Discovery for ordinary repository work.
